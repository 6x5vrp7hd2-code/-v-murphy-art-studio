# V. Murphy Art Studio

A small static website for GitHub Pages presenting a family collection of original paintings by V. Murphy and preparing selected works for sale as fine art prints.

## Current collection

The first five catalogue entries are:
- The Courtyard Café
- Blue Awnings
- Village Garden (signed and dated 2013)
- The Square — temporary screenshot/reference image; replace before launch
- Red Composition

The titles are working catalogue titles unless an original title is known. The website deliberately avoids inventing locations, biography or stories that the family cannot verify.

## Before publishing

1. In `index.html`, replace `YOUR-EMAIL@example.com` with the contact email you want to use.
2. Replace the generic Etsy URL (`https://www.etsy.com/`) with the final V. Murphy Art Studio shop URL when it is live.
3. Replace `assets/the-square-reference.jpeg` with the original photograph or scan. The current file is a phone screenshot and is included only as a temporary catalogue reference.
4. Ideally replace all framed/glazed photographs with glare-free, high-resolution captures before using them for print production.
5. Once a print is approved, change its status text and link its artwork/product button to the corresponding Etsy listing.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `v-murphy-art-studio`.
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages** in GitHub.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the public `github.io` address after deployment.

## Recommended sales flow

**V. Murphy website → individual Etsy listing → Etsy checkout**

This keeps the public website simple and inexpensive while Etsy handles checkout, payment, tax and order management.

## Print-production note

The website photographs are suitable for cataloguing and presentation, but a print master should be made from a high-resolution, straight-on, glare-free photograph or scan of each artwork. Colour should be checked against the physical original before the first print is sold.
